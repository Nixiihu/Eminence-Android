# Eminence Android Complete Unity Project

This package turns the earlier Assets-only Eminence test harness into a standard Unity project layout with:

- Assets/
- Packages/
- ProjectSettings/
- A buildable demo scene
- A simple purple development UI
- Legit / Rage test profiles
- Flag/Log development testing
- Input-gated aim test logic
- Recoil and lead-aim test components
- Fast-switch test component
- FPS/frame-time telemetry

Startup behavior: gameplay test modules are OFF.

This is intended for testing your own Unity game's anti-cheat in a development build. It is not an external injector, memory patcher, or anti-detection tool.
